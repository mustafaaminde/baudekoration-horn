1. Cloudflare Dashboard öffnen und den gewünschten Worker auswählen.
2. New deployment / Upload static files öffnen.
3. Den Ordner "baudekoration-horn-website" auswählen, in dem index.html direkt liegt.
4. Deployment abschließen und anschließend die Worker-URL neu laden.
